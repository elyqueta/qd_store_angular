# 05 · Internacionalização (Transloco)

Decisão D-004: **Transloco** (runtime, troca de idioma sem recarregar).

## Configuração

- Idiomas: `pt` (padrão, pt-AO/pt-PT) agora; para adicionar `en` no futuro, criar `en.json` e actualizar a configuração, o loader e o serviço de idioma.
- Ficheiros: `src/assets/i18n/pt/*.json`, divididos por domínio (`shared`, `auth`, `account`, `commerce`, `admin`, `seo`, `public`). O loader importa e agrega estes módulos mantendo as chaves Transloco estáveis. Traduções de novos domínios devem ser adicionadas em ficheiro próprio e incluídas no loader.
- Idioma ativo persistido em `localStorage` (`qd.lang`) e refletido em `<html lang>`.
- O loader global importa o JSON estático para o bundle; assim, as traduções estão disponíveis no browser e no SSR sem depender de pedidos HTTP relativos durante a renderização no servidor.
- O Angular copia `src/assets/` para a saída pública; as traduções actuais são importadas estaticamente e agregadas no arranque, incluindo no SSR.
- A inicialização no servidor usa `pt`; no browser, restaura `qd.lang` apenas se corresponder a um idioma disponível. Falhas de leitura ou escrita no armazenamento são registadas e não impedem o arranque.
- O idioma `pt` continua a ser carregado como um único idioma pelo Transloco; a divisão dos JSON é apenas organizacional e não altera as chaves usadas nas páginas.

## Regras

1. Chaves em inglês, estáveis, hierárquicas: `catalog.product.addToCart`, `auth.login.title`.
2. Nada de concatenar frases; usar parâmetros: `"greeting": "Olá, {{name}}"`.
3. Plurais e datas/moedas via `Intl` com o locale ativo (`Intl.NumberFormat('pt-AO', { style:'currency', currency:'AOA' })`).
4. Mensagens de validação de formulário também traduzidas.
5. **Erros da API:** hoje o back-end devolve `message` em pt-PT sem código. Estratégia: mapear por **status HTTP** e por `details[].field` para chaves i18n; usar o `message` da API só como fallback. Pedir ao back-end códigos de erro estáveis (lacuna L-04).
6. Conteúdo vindo da BD (nomes/descrições de produtos, categorias) **não** é traduzido nesta fase.
7. SEO multilíngue (`hreflang`, URLs por idioma) fica para quando existir `en`; deixar o `SeoService` preparado para receber o idioma.
